## Deskripsi

Praktikum pertama ini mengajarkan saya bagaimana cara saya untuk adaptasi yang sebelumnya hanya menggunakan bahasa pemrograman dart saja, namun saat ini ada peningkatan dengan menggunakan kerangka kerja (framework) flutter, yang dimana kita harus mengikuti aturan yang ada di framework ini sesuai dengan dokumentasi, dan untuk implementasi dart nya juga sama, namun perbedaanya ketika menggunakan framework lebih terstruktur, flutter juga memiliki widget yang berfungsi sebagai layout mobile.
